# Реализованные функции

## ✅ Авторизация и регистрация
- Регистрация по email + пароль
- Вход в систему
- JWT токены для аутентификации
- Хэширование паролей (bcrypt)
- Защита роутов (middleware)

## ✅ Управление группой
- Создание группы (до 5 человек в Free плане)
- Приглашение участников по email
- Генерация уникальной ссылки-инвайта
- Просмотр информации о группе
- Иконки кластера с индикацией количества участников
- Поддержка разных тарифов (Free, Premium, Team, Lifetime)
- Роли: owner, member

## ✅ Задачи (Tasks)
- Создание задач (личные и общие)
- Поля:
  - Название
  - Описание
  - Дедлайн
  - Статус (новая/в процессе/завершена/отложена)
  - Приоритет (низкий/средний/высокий)
  - Ответственный (я/другие/все)
  - Флаг "общая задача"
- Завершение задач
- Редактирование и удаление задач
- Фильтрация (все/активные/завершённые/сегодня/срочные)
- Отображение владельца задачи

## ✅ События календаря (Events)
- Создание событий
- Поля:
  - Название
  - Описание
  - Дата и время начала/конца
  - Весь день (да/нет)
  - Место
  - Участники (я/другие/все)
- Просмотр списка событий
- Редактирование и удаление событий
- Группировка по датам (Сегодня/Завтра/На неделе/Позже)
- Автоопределение типа события по ключевым словам
- Отображение создателя события

## ✅ Списки покупок
- Создание списков покупок
- Добавление товаров
- Отметка купленного
- Отображение кто добавил/купил товар

## ✅ PWA функции
- Установка как приложение
- Работа офлайн (service worker)
- Push-уведомления
- Адаптивный дизайн
- Иконки и манифест

## ✅ Интерфейс
- Главная страница (лендинг)
- Страница регистрации
- Страница входа
- Онбординг (настройка группы)
- Дашборд с задачами и событиями
- Отдельная страница задач с фильтрами
- Страница списков покупок
- Настройки с блоками (Группа/Приложение/Уведомления/Аккаунт)
- Адаптивный дизайн (Tailwind CSS)
- Цветовая индикация статусов и приоритетов
- Иконки кластера для групп
