# Реализованные функции MVP

## ✅ Авторизация и регистрация
- Регистрация по email + пароль
- Вход в систему
- JWT токены для аутентификации
- Хэширование паролей (bcrypt)
- Защита роутов (middleware)

## ✅ Управление парой
- Создание пространства пары
- Приглашение партнёра по email
- Генерация уникальной ссылки-инвайта
- Просмотр информации о паре
- Ограничение: максимум 2 участника

## ✅ Задачи (Tasks)
- Создание задач (личные и общие)
- Поля:
  - Название
  - Описание
  - Дедлайн
  - Статус (новая/в процессе/завершена/отложена)
  - Приоритет (низкий/средний/высокий)
  - Ответственный (я/партнёр/оба)
  - Флаг "общая задача"
- Завершение задач
- Фильтрация (все/активные/завершённые)
- Отображение владельца задачи

## ✅ События календаря (Events)
- Создание событий
- Поля:
  - Название
  - Описание
  - Дата и время начала/конца
  - Весь день (да/нет)
  - Место
  - Участники (я/партнёр/оба)
- Просмотр списка событий
- Отображение создателя события

## ✅ Интерфейс
- Главная страница (лендинг)
- Страница регистрации
- Страница входа
- Онбординг (настройка пары)
- Дашборд с задачами и событиями
- Отдельная страница задач с фильтрами
- Адаптивный дизайн (Tailwind CSS)
- Цветовая индикация статусов и приоритетов

## ✅ API эндпоинты
### Auth
- POST /api/auth/register
- POST /api/auth/login

### Couple
- POST /api/couple/create
- POST /api/couple/invite
- GET /api/couple/me

### Tasks
- GET /api/tasks
- POST /api/tasks
- PATCH /api/tasks/:id
- DELETE /api/tasks/:id
- POST /api/tasks/:id/complete

### Events
- GET /api/events
- POST /api/events

### Notifications
- GET /api/notifications

## 🔄 Планируется в следующих версиях

### Этап 2
- Подтверждение планов партнёром
- Комментарии к задачам и событиям
- Email уведомления
- Редактирование и удаление событий
- Повторяющиеся задачи
- Напоминания
- Календарный вид (месяц/неделя)

### Этап 3
- Push-уведомления (PWA)
- Синхронизация с Google Calendar
- Статистика выполнения
- Тёмная тема
- Экспорт данных
- Метки (теги) для задач
- Вложения к задачам

## 🛠 Технический стек
- **Frontend**: Next.js 14, React, TypeScript
- **Styling**: Tailwind CSS
- **Backend**: Next.js API Routes
- **Database**: PostgreSQL + Prisma ORM
- **Auth**: JWT + bcrypt
- **Validation**: Zod

## 📊 Структура базы данных
- users - пользователи
- couple_spaces - пространства пар
- couple_members - связь пользователей и пар
- invites - приглашения
- tasks - задачи
- events - события
- comments - комментарии (готово к использованию)
- notifications - уведомления (готово к использованию)
