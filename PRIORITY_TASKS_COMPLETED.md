## 🚀 Как использовать

### Toast
```tsx
setToast({ message: 'Успешно!', type: 'success' });
setToast({ message: 'Ошибка!', type: 'error' });
```

### ConfirmDialog
```tsx
setConfirmDialog({
  title: 'Удалить?',
  message: 'Это действие нельзя отменить.',
  onConfirm: async () => {
    // действие
  }
});
```

### LoadingSpinner
```tsx
{isSubmitting ? (
  <LoadingSpinner size="lg" text="Загрузка..." />
) : (
  <Form />
)}
```
