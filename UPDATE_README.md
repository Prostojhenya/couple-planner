# 🎉 Обновление: Групповой планер с иконками кластера

## 🚀 Что нового?

Приложение обновлено с концепции "планера для пар" на **"групповой планер"** с поддержкой до 5 участников в бесплатной версии.

### Ключевые изменения:

1. **👥 Иконки кластера** - красивые визуальные индикаторы группы
2. **📊 Тарифные планы** - Free (5), Premium (15), Team (50), Lifetime (50)
3. **🎨 Новый дизайн** - обновлённый UI с акцентом на группы
4. **📝 Роли** - owner и member с разными правами

---

## ⚡ Быстрый старт

### 1. Применить миграцию БД
```bash
npx prisma db push
```

### 2. Запустить приложение
```bash
npm run dev
```

### 3. Проверить изменения
Откройте http://localhost:3000

## 🐛 Проблемы?

### Миграция не применяется
```bash
# Проверьте подключение к БД
npx prisma db pull

# Или примените вручную через SQL
# См. QUICK_START.md
```

### Иконка не отображается
- Очистите кэш браузера (Ctrl+Shift+R)
- Проверьте консоль на ошибки (F12)
- Перезапустите dev-сервер

### Нужна помощь?
1. Проверьте `QUICK_START.md`
2. Проверьте `CHECKLIST.md`
3. Создайте issue в репозитории
