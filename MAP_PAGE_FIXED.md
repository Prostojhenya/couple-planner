## Что вы увидите на `/map`

### Визуальные элементы:

1. **Центральный HUB** (128px)
   - Чёрный круг в центре экрана
   - Инициалы: "Я | Ю"
   - Счётчик кластеров: "X CLUSTERS"

2. **Кластеры** (96px) - расположены по кругу вокруг HUB
   - 🔵 **TASKS** - задачи (синяя иконка)
   - 🟢 **SHOP** - покупки (зелёная иконка)
   - 🟣 **EVENTS** - события (фиолетовая иконка)
   - Счётчик задач в каждом кластере
   - Аватары участников внизу

3. **Связи**
   - Пунктирные изогнутые линии от HUB к кластерам
   - Цвет: #D1D5DB (светло-серый)

4. **Фон**
   - Светло-серая сетка (grid)
   - Размер ячейки: 40px

### Интерактивность:

- **Клик на кластер** → раскрывает/сворачивает задачи
- **Долгое нажатие на кластер** → открывает панель управления участниками
- **Раскрытый кластер** → показывает задачи как маленькие круги (32px)

## Если не видите кластеры

Проверьте консоль браузера (F12) на наличие ошибок. Возможные причины:

1. **Нет данных** - кластеры генерируются автоматически при загрузке страницы
2. **Ошибка рендеринга** - проверьте размеры окна браузера
3. **JavaScript отключён** - страница требует JavaScript
