# 📋 Сводка: Ошибка 401 на Production

## Что произошло

Ошибка `POST /api/auth/login → 401 (Unauthorized)` означает, что пользователь не существует в production базе данных.

## Почему это происходит

1. Production база данных пустая (нет пользователей)
2. Или вы пытаетесь войти с неправильными данными
3. Или миграции не применены (но это даст 500, а не 401)

## ✅ Что нужно сделать

### Шаг 1: Зарегистрируйтесь
Откройте: https://couple-planner-ten.vercel.app/auth/register

### Шаг 2: Войдите
Используйте данные из регистрации

### Шаг 3: Создайте группу
Пройдите onboarding и создайте пространство

## 🛠️ Альтернатива: Создать пользователя через скрипт

```bash
# Получите DATABASE_URL из Vercel Dashboard
# Settings → Environment Variables → DATABASE_URL

# Создайте пользователя
DATABASE_URL="your_production_url" node create-production-user.js
```

Скрипт создаст пользователя с данными:
- Email: test@example.com
- Пароль: password123

Ошибка 401 - это **нормально** для новой production базы. Просто зарегистрируйтесь через UI или создайте пользователя через скрипт.
