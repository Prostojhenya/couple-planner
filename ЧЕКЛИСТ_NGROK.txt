╔════════════════════════════════════════════════════════════╗
║         📱 ЧЕКЛИСТ: Push-уведомления на iPhone            ║
╚════════════════════════════════════════════════════════════╝

┌─ ШАГ 1: РЕГИСТРАЦИЯ NGROK ─────────────────────────────────┐
│                                                             │
│ 1. Откройте: https://ngrok.com/                            │
│ 2. Нажмите "Sign up" (бесплатно)                           │
│ 3. Зарегистрируйтесь                                       │
│                                                             │
└─────────────────────────────────────────────────────────────┘

┌─ ШАГ 2: ПОЛУЧИТЕ ТОКЕН ────────────────────────────────────┐
│                                                             │
│ 1. После входа откройте:                                   │
│    https://dashboard.ngrok.com/get-started/your-authtoken  │
│                                                             │
│ 2. Скопируйте authtoken                                    │
│    (выглядит как: 2abc123def456ghi789jkl)                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘

┌─ ШАГ 3: НАСТРОЙТЕ NGROK ───────────────────────────────────┐
│                                                             │
│ Выполните в терминале (замените YOUR_TOKEN):               │
│                                                             │
│   ngrok config add-authtoken YOUR_TOKEN                    │
│                                                             │
│ Пример:                                                    │
│   ngrok config add-authtoken 2abc123def456ghi789jkl        │
│                                                             │
└─────────────────────────────────────────────────────────────┘

┌─ ШАГ 4: ЗАПУСТИТЕ ТУННЕЛЬ ─────────────────────────────────┐
│                                                             │
│ Автоматический способ (рекомендуется):                     │
│                                                             │
│   node start-ngrok.js                                      │
│                                                             │
│ ИЛИ вручную:                                               │
│                                                             │
│   ngrok http 3000                                          │
│                                                             │
│ Скопируйте HTTPS URL (например: https://abc123.ngrok.io)  │
│                                                             │
└─────────────────────────────────────────────────────────────┘

┌─ ШАГ 5: ОБНОВИТЕ .ENV (если запускали вручную) ───────────┐
│                                                             │
│ Откройте файл .env и обновите:                             │
│                                                             │
│   NEXTAUTH_URL="https://abc123.ngrok.io"                   │
│                                                             │
│ (замените abc123 на ваш реальный URL)                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘

┌─ ШАГ 6: ПЕРЕЗАПУСТИТЕ СЕРВЕР ─────────────────────────────┐
│                                                             │
│   npm run dev                                              │
│                                                             │
└─────────────────────────────────────────────────────────────┘

┌─ ШАГ 7: НАСТРОЙТЕ IPHONE ──────────────────────────────────┐
│                                                             │
│ На iPhone:                                                 │
│                                                             │
│ 1. Откройте Safari (не Chrome!)                            │
│                                                             │
│ 2. Перейдите на ngrok URL                                  │
│    (например: https://abc123.ngrok.io)                     │
│                                                             │
│ 3. Войдите:                                                │
│    Email: test@test.com                                    │
│    Пароль: test1234                                        │
│                                                             │
│ 4. Установите PWA:                                         │
│    - Кнопка "Поделиться" (внизу экрана)                    │
│    - "На экран «Домой»"                                    │
│    - "Добавить"                                            │
│                                                             │
│ 5. Запустите через иконку на домашнем экране               │
│                                                             │
│ 6. Разрешите уведомления                                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘

┌─ ШАГ 8: ПРОВЕРЬТЕ РАБОТУ ──────────────────────────────────┐
│                                                             │
│ На компьютере выполните:                                   │
│                                                             │
│   node test-push-notification.js                           │
│                                                             │
│ На iPhone должно прийти уведомление! 🎉                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘

╔════════════════════════════════════════════════════════════╗

❌ ngrok не запускается:
   → ngrok config add-authtoken YOUR_TOKEN

❌ Приложение не открывается:
   → Проверьте, что используете HTTPS URL
   → Проверьте, что ngrok и dev-сервер запущены

❌ Уведомления не приходят:
   → iOS 16.4 или выше?
   → Приложение установлено как PWA?
   → Разрешения даны в Настройках iOS?
