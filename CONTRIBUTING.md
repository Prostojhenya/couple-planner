# Руководство по внесению вклада

Спасибо за интерес к проекту "Планер для двоих"! 

## Как внести вклад

### 1. Fork репозитория
Создайте fork проекта на GitHub

### 2. Клонируйте ваш fork
```bash
git clone https://github.com/your-username/couple-planner.git
cd couple-planner
```

### 3. Создайте ветку для изменений
```bash
git checkout -b feature/amazing-feature
```

### 4. Внесите изменения
- Следуйте стилю кода проекта
- Добавьте комментарии где необходимо
- Обновите документацию если нужно

### 5. Commit изменений
```bash
git add .
git commit -m "feat: добавлена потрясающая функция"
```

Используйте conventional commits:
- `feat:` - новая функция
- `fix:` - исправление бага
- `docs:` - изменения в документации
- `style:` - форматирование кода
- `refactor:` - рефакторинг
- `test:` - добавление тестов
- `chore:` - обновление зависимостей и т.д.

### 6. Push в ваш fork
```bash
git push origin feature/amazing-feature
```

### 7. Создайте Pull Request
Откройте PR в основной репозиторий с описанием изменений

## Стандарты кода

### TypeScript
- Используйте строгую типизацию
- Избегайте `any`
- Документируйте сложные типы

### React
- Используйте функциональные компоненты
- Hooks для состояния
- Prop types через TypeScript interfaces

### Стиль
- Tailwind CSS для стилей
- Следуйте существующим паттернам
- Адаптивный дизайн обязателен

### API
- Валидация через Zod
- Обработка ошибок
- Правильные HTTP статусы
