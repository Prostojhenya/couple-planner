# Быстрая настройка PWA уведомлений

## Шаг 1: Генерация VAPID ключей

Запустите команду:

```bash
node generate-vapid-keys.js
```

## Шаг 2: Добавьте ключи в .env

Скопируйте сгенерированные ключи в файл `.env`:

```env
NEXT_PUBLIC_VAPID_PUBLIC_KEY="ваш-публичный-ключ"
VAPID_PRIVATE_KEY="ваш-приватный-ключ"
VAPID_SUBJECT="mailto:your-email@example.com"
```

## Шаг 3: Перезапустите приложение

```bash
npm run dev
```

## Шаг 4: Тестирование

1. Откройте приложение в браузере
2. Войдите в аккаунт
3. На главной странице появится предложение включить уведомления
4. Нажмите "Включить уведомления"
5. Разрешите уведомления в браузере
6. Создайте задачу для партнёра с другого устройства
7. Проверьте, что уведомление пришло
