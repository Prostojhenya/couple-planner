# 🔔 Решение проблемы с push-уведомлениями на iPhone

## ✅ Что я сделал:

1. **Сгенерировал VAPID ключи** и добавил в `.env`
2. **Запустил dev-сервер** на http://localhost:3000
3. **Создал тестовый скрипт** `test-push-notification.js`
4. **Улучшил компонент уведомлений** - теперь показывает предупреждения для iOS

## ⚠️ Главная проблема:

**На iPhone push-уведомления НЕ работают через обычный Safari!**

### Требования для iOS:
1. ✅ iOS 16.4 или выше
2. ❌ Приложение должно быть установлено как PWA (через "На экран «Домой»")
3. ❌ Требуется HTTPS (localhost не работает на iPhone)

## 🚀 Как заставить работать на iPhone:

### Вариант 1: Быстрый тест через ngrok (5 минут)

```bash
# 1. Установите ngrok
npm install -g ngrok

# 2. Запустите туннель (в новом терминале)
ngrok http 3000

# 3. Скопируйте HTTPS URL (например: https://abc123.ngrok.io)

# 4. Обновите .env:
NEXTAUTH_URL="https://abc123.ngrok.io"

# 5. Перезапустите сервер
npm run dev
```

**На iPhone:**
1. Откройте Safari
2. Перейдите на `https://abc123.ngrok.io`
3. Войдите в систему
4. Нажмите кнопку "Поделиться" (квадрат со стрелкой вверх)
5. Выберите "На экран «Домой»"
6. Запустите приложение через иконку на домашнем экране
7. Разрешите уведомления

### Вариант 2: Deploy на Vercel (рекомендуется)

```bash
# 1. Установите Vercel CLI
npm install -g vercel

# 2. Deploy
vercel

# 3. Следуйте инструкциям
```

**На iPhone:**
1. Откройте Safari
2. Перейдите на ваш Vercel URL (например: `https://your-app.vercel.app`)
3. Войдите в систему
4. Установите как PWA (через "На экран «Домой»")
5. Разрешите уведомления

## 🧪 Тестирование:

### На компьютере (Chrome/Edge):
```bash
# 1. Откройте http://localhost:3000
# 2. Войдите в систему
# 3. Разрешите уведомления
# 4. Запустите тест:
node test-push-notification.js
```

Должно прийти тестовое уведомление!

### На iPhone:
1. Установите приложение как PWA (см. выше)
2. Разрешите уведомления
3. Создайте задачу для партнёра с другого устройства
4. Уведомление должно прийти

## 📱 Проверка настроек iOS:

1. Настройки → Уведомления → [Ваше приложение]
2. Убедитесь, что:
   - Разрешить уведомления: ВКЛ
   - Звуки: ВКЛ
   - Баннеры: ВКЛ

## 🔍 Диагностика:

Если уведомления всё равно не приходят:

1. **Проверьте версию iOS:**
   - Настройки → Основные → Об этом устройстве
   - Должна быть 16.4 или выше

2. **Проверьте, что приложение установлено как PWA:**
   - Запускается через иконку на домашнем экране
   - Открывается в полноэкранном режиме (без адресной строки Safari)

3. **Проверьте HTTPS:**
   - URL должен начинаться с `https://`
   - `http://localhost` НЕ работает на iPhone

4. **Проверьте подписку:**
   ```bash
   node test-push-notification.js
   ```
   Должен показать вашего пользователя в списке

## 💡 Альтернативы:

Если iOS push всё равно не работает:

1. **OneSignal** - сторонний сервис, лучше работает на iOS
2. **Email уведомления** - работают везде
3. **In-app уведомления** - показ внутри приложения
