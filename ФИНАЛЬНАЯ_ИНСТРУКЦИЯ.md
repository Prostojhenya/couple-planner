### Шаг 1: Загрузить на GitHub (2 минуты)

**Вариант А: Через GitHub Desktop (проще)**

1. Скачайте и установите: https://desktop.github.com/
2. Откройте GitHub Desktop
3. File → Add Local Repository
4. Выберите папку: `G:\Users\prost\Desktop\планер`
5. Publish repository
6. Снимите галочку "Keep this code private" (если хотите публичный)
7. Нажмите "Publish repository"

**Готово!** Код на GitHub.

---

**Вариант Б: Через командную строку**

1. Создайте репозиторий на GitHub:
   - Откройте https://github.com/new
   - Название: `couple-planner`
   - Нажмите "Create repository"

2. Выполните команды (замените YOUR_USERNAME):

```bash
git remote add origin https://github.com/YOUR_USERNAME/couple-planner.git
git branch -M main
git push -u origin main
```

**Готово!** Код на GitHub.

### Шаг 2: Deploy на Vercel (3 минуты)

1. **Откройте** https://vercel.com/

2. **Зарегистрируйтесь:**
   - Нажмите "Sign Up"
   - Выберите "Continue with GitHub"
   - Разрешите доступ

3. **Создайте проект:**
   - Нажмите "Add New..." → "Project"
   - Найдите репозиторий `couple-planner`
   - Нажмите "Import"

4. **Настройте проект:**
   - Project Name: `couple-planner` (или любое другое)
   - Framework Preset: Next.js (должно определиться автоматически)
   - Нажмите "Deploy"

**Подождите 2-3 минуты...**

5. **Получите URL:**
   - После deploy вы увидите: "Congratulations!"
   - Ваш URL: `https://couple-planner.vercel.app` (или другой)
   - **Скопируйте этот URL!**

## 💾 Улучшение: PostgreSQL база данных

Сейчас используется SQLite (файл dev.db). Для production лучше PostgreSQL:

### Вариант 1: Vercel Postgres (рекомендуется)

1. В Vercel проекте: **Storage** → **Create Database** → **Postgres**
2. Скопируйте `POSTGRES_PRISMA_URL`
3. Settings → Environment Variables
4. Обновите `DATABASE_URL` на новое значение
5. Redeploy

### Вариант 2: Supabase (бесплатно)

1. Откройте https://supabase.com/
2. New project → заполните данные
3. Settings → Database → Connection string → URI
4. Скопируйте и обновите `DATABASE_URL` в Vercel
5. Redeploy

**После смены базы данных:**

```bash
# Локально обновите DATABASE_URL в .env
DATABASE_URL="postgresql://..."

# Примените миграции
npx prisma migrate deploy
```

## 🐛 Если что-то не работает:

### Приложение не открывается:
- Проверьте, что deploy завершился успешно
- Проверьте логи в Vercel: Deployments → View Function Logs

### Push-уведомления не работают:
- Проверьте, что все VAPID переменные добавлены
- Проверьте, что приложение установлено как PWA
- Переустановите PWA на iPhone

### Build ошибка:
- Проверьте логи в Vercel
- Убедитесь, что локально `npm run build` работает
