## 🎯 Что нужно сделать СЕЙЧАС

### 1. Проверь Firebase в Vercel

Открой в браузере: **https://couple-planner-ten.vercel.app/api/debug/firebase-status**

Должно показать:
```json
{
  "firebaseConfigured": true,
  "missingVars": []
}
```

❌ Если `firebaseConfigured: false` - значит Firebase переменные НЕ добавлены в Vercel!

### 2. Если Firebase не настроен

Зайди в Vercel:
https://vercel.com/prostojhenyas-projects/couple-planner/settings/environment-variables

Добавь все 6 переменных:

```
FIREBASE_PROJECT_ID = tasktango-uuyq4
FIREBASE_PRIVATE_KEY_ID = ea426e1b8d361ad1321d38e6db824a90fa5c11ea
FIREBASE_PRIVATE_KEY = -----BEGIN PRIVATE KEY-----\nMIIEvgIBADANBgkqhkiG9w0BAQEFAASCBKgwggSkAgEAAoIBAQCxjVKN...(полный ключ из JSON файла)...\n-----END PRIVATE KEY-----\n
FIREBASE_CLIENT_EMAIL = firebase-adminsdk-fbsvc@tasktango-uuyq4.iam.gserviceaccount.com
FIREBASE_CLIENT_ID = 110304382595328323748
FIREBASE_CLIENT_CERT_URL = https://www.googleapis.com/robot/v1/metadata/x509/firebase-adminsdk-fbsvc%40tasktango-uuyq4.iam.gserviceaccount.com
```

⚠️ **ВАЖНО**: 
- В `FIREBASE_PRIVATE_KEY` замени все переносы строк на `\n`
- Должно быть: `-----BEGIN PRIVATE KEY-----\nMIIEvgIB...`
- НЕ должно быть реальных переносов строк!

После добавления переменных Vercel автоматически передеплоит.

### 3. Партнёр должен переподписаться

**Ольга** тоже должна на своём iPhone:

1. Настройки → Safari → Уведомления
2. Удалить `couple-planner-ten.vercel.app`
3. Открыть PWA заново
4. Разрешить уведомления
