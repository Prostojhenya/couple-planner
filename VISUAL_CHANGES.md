## 📊 Цветовая индикация бейджа

Бейдж меняет цвет в зависимости от заполненности:

| Заполненность | Цвет | Пример |
|---------------|------|--------|
| < 50% | 🟢 Зелёный | 2 из 5 |
| 50-80% | 🟡 Жёлтый | 8 из 15 |
| > 80% | 🔴 Красный | 45 из 50 |

## 🔄 Анимации

### Hover на иконке кластера
```
Обычное состояние → Увеличение (scale: 1.05)
                  → Тень становится ярче
```

### Загрузка
```
Иконка кластера → Bounce анимация
                → Spinner под иконкой
```
