# 🚀 Обновление: Групповой планер

## Что нового?

### 👥 Иконки кластера
Теперь вместо эмодзи 💑 используются красивые иконки кластера, которые показывают:
- Количество участников в группе
- Тип подписки (цветовая индикация)
- Лимит участников

### 📊 Тарифные планы
- **Free**: до 5 участников (серая иконка 👥)
- **Premium**: до 15 участников (фиолетовая иконка 👥✨)
- **Team**: до 50 участников (золотая иконка 👥🚀)
- **Lifetime**: до 50 участников (радужная иконка 👥⭐)

### 🔄 Изменения в терминологии
- "Пара" → "Группа"
- "Партнёр" → "Участник"
- "Создать пару" → "Создать группу"

## Как обновить?

### Шаг 1: Применить миграцию БД

```bash
# Вариант 1: Автоматическая миграция
npm run db:push

# Вариант 2: Создать миграцию
npx prisma migrate dev --name add_group_features

# Вариант 3: Применить существующую миграцию
npx prisma migrate deploy
```

### Шаг 2: Перезапустить приложение

```bash
# Остановить текущий процесс (Ctrl+C)
# Запустить заново
npm run dev
```

### Шаг 3: Проверить изменения

Откройте http://localhost:3000 и проверьте:

1. **Header** - иконка кластера вместо 💑
2. **Настройки** - блок "Группа" вместо "Пара"
3. **Онбординг** - новый дизайн с иконкой кластера
4. **Список участников** - показывает всех участников группы

## Проблемы?

### Ошибка миграции БД
```bash
# Сбросить БД (ВНИМАНИЕ: удалит все данные!)
npx prisma migrate reset

# Применить все миграции заново
npx prisma migrate deploy
```

### Иконка не отображается
- Проверьте импорт `GroupClusterIcon` в файле
- Убедитесь, что передаёте все обязательные props
- Проверьте консоль браузера на ошибки

### Старые данные не обновились
```bash
# Вручную обновить через Prisma Studio
npx prisma studio

# Или через SQL
UPDATE couple_spaces SET "maxMembers" = 5, "subscription" = 'free';
```
