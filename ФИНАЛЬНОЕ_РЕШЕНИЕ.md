# 🎯 Финальное решение для iOS push-уведомлений

## ✅ Что подтвердилось

Через ngrok работало на iPhone! Значит iOS Safari **поддерживает Web Push API** с VAPID ключами.

## 🔍 Почему сейчас не работает

В базе данных сохранены **старые подписки**, которые были созданы когда мы пытались использовать Firebase. Эти подписки не валидны.

## 🚀 Решение (3 шага)

### Шаг 1: Дождись деплоя

Проверь что новый код задеплоился:
https://vercel.com/prostojhenyas-projects/couple-planner

Должен быть зелёный статус "Ready".

### Шаг 2: Очисти старые подписки

Открой в браузере (можно с компьютера):
```
https://couple-planner-ten.vercel.app/api/debug/clear-subscriptions
```

Метод: **POST** (можно использовать Postman, или я создам кнопку)

Или просто открой в консоли браузера:
```javascript
fetch('https://couple-planner-ten.vercel.app/api/debug/clear-subscriptions', {
  method: 'POST'
}).then(r => r.json()).then(console.log)
```

Должно показать:
```json
{
  "success": true,
  "clearedCount": 2,
  "message": "All push subscriptions cleared"
}
```

### Шаг 3: Переподпишитесь оба

**На iPhone (Ольга):**
1. Открой PWA
2. Должна появиться кнопка "Включить уведомления"
3. Нажми и разреши

**На iPhone (Женя):**
То же самое

**На Desktop (если используете):**
То же самое

### Шаг 4: Проверь

Создай задачу для партнёра. Уведомление должно прийти!

## 🔍 Как проверить что всё правильно

После подписки открой:
https://couple-planner-ten.vercel.app/api/couple/me

Должно показать:
```json
"hasPushSubscription": true,
"pushSubscriptionPreview": "https://web.push.apple.com/..."
```

Это нормально! Это тот же формат что работал через ngrok.

## 📊 Логи Vercel

После создания задачи в логах должно быть:
```
✅ VAPID push notification sent to user <userId>
```

Вместо:
```
❌ Error sending VAPID push notification: 403
```

---

## 💡 Почему через ngrok работало

Через ngrok:
- Использовали обычный Web Push API
- VAPID ключи
- Свежие подписки

Через Vercel (сейчас):
- Пытались использовать Firebase (не работает на iOS)
- Старые невалидные подписки в БД
- После очистки и переподписки должно работать!
