# 🔄 Как переподписаться на уведомления (iOS)

## 🔍 Проблема

Из логов видно:
```
Error sending VAPID push notification: 
statusCode: 403
body: '{"reason":"BadAuthorizationHeader"}'
endpoint: 'https://web.push.apple.com/...'
```

Это значит что в базе данных сохранена **старая VAPID подписка**, которая не работает на iOS. Нужно получить **новый FCM токен**.

## ✅ Решение: Переподписаться

### На iPhone:

1. **Открой настройки Safari**:
   - Настройки → Safari → Уведомления
   - Найди `couple-planner-ten.vercel.app`
   - Удали разрешение (свайп влево → Удалить)

2. **Открой PWA заново**:
   - Закрой приложение полностью (свайп вверх)
   - Открой через иконку на домашнем экране

3. **Разреши уведомления**:
   - Должен появиться запрос на разрешение
   - Нажми "Разрешить"
   - Подожди пока появится "✅ Уведомления успешно включены!"

4. **Проверь**:
   - Создай задачу для партнёра
   - Уведомление должно прийти

### Альтернативный способ (если не помогло):

1. **Удали PWA**:
   - Долгое нажатие на иконку
   - "Удалить приложение"

2. **Установи заново**:
   - Открой в Safari: https://couple-planner-ten.vercel.app
   - Поделиться → "На экран Домой"
   - Открой через иконку
   - Разреши уведомления

## 🔍 Как проверить что получен FCM токен

Открой консоль в Safari (на iPhone):
```javascript
// Должен показать FCM токен (длинная строка)
localStorage.getItem('fcmToken')
```

Или проверь в логах Vercel - должна быть строка:
```
✅ FCM notification sent: projects/tasktango-uuyq4/messages/...
```

Вместо:
```
❌ Error sending VAPID push notification
```

## 💡 Почему это нужно

- **Старая система (VAPID)**: не работает на iOS Safari
- **Новая система (FCM)**: работает на iOS 16.4+
- Подписки хранятся в БД, поэтому нужно обновить

## 🎯 После переподписки

Всё должно работать автоматически:
- Создаёшь задачу → партнёр получает уведомление
- Партнёр создаёт задачу → ты получаешь уведомление
