┌─ РЕШЕНИЯ ДЛЯ iOS ───────────────────────────────────────────┐
│                                                             │
│ 1️⃣ Safari Web Push ID (бесплатно, iOS 16.4+):              │
│    • Зайти на developer.apple.com                          │
│    • Создать Web Push ID                                   │
│    • Загрузить сертификат в OneSignal                      │
│    • Работает только на iOS 16.4+                          │
│                                                             │
│ 2️⃣ Apple Developer + APNs ($99/год):                       │
│    • Купить Apple Developer Program                        │
│    • Создать APNs Authentication Key                       │
│    • Настроить в OneSignal                                 │
│    • Полная поддержка всех версий iOS                      │
│                                                             │
│ 3️⃣ Оставить как есть (бесплатно):                          │
│    • Работает на Android/Desktop                           │
│    • Не работает на iOS                                    │
