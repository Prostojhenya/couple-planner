## Как тестировать:

1. **Очистите кэш браузера и localStorage:**
   - Откройте DevTools (F12)
   - Application → Storage → Clear site data

2. **Перезапустите dev сервер:**
   ```bash
   npm run dev
   ```

3. **Войдите в приложение:**
   - Откройте http://localhost:3000
   - Войдите в систему

4. **Установите PWA:**
   - В Chrome: три точки → "Установить приложение"
   - Или используйте кнопку установки в адресной строке

5. **Запустите через ярлык:**
   - Закройте все окна приложения
   - Запустите через ярлык на рабочем столе
   - Должна показаться анимация загрузки, затем dashboard

## Если проблема сохраняется:

1. **Проверьте консоль браузера (F12):**
   - Есть ли ошибки?
   - Есть ли бесконечные запросы?

2. **Проверьте Network tab:**
   - Какие запросы выполняются?
   - Есть ли редиректы?

3. **Проверьте localStorage:**
   - Application → Local Storage
   - Есть ли токен?

4. **Попробуйте удалить PWA и переустановить:**
   - Удалите приложение
   - Очистите кэш
   - Установите заново

## Возможные причины если не работает:

1. **Кэш Service Worker** - нужно удалить в DevTools → Application → Service Workers
2. **Старый кэш Next.js** - удалите папку `.next` и перезапустите
3. **Проблема с токеном** - проверьте что токен сохраняется в localStorage
4. **Проблема с API** - проверьте что API endpoints работают
