## Проблемы и решения

Если что-то не работает:

### База данных
```bash
# Пересоздать схему
npm run db:push

# Проверить данные
npm run db:studio
```

### Зависимости
```bash
# Переустановить
rm -rf node_modules package-lock.json
npm install
```

### Кэш Next.js
```bash
# Очистить
rm -rf .next
npm run dev
```

### Порт занят
```bash
# Использовать другой порт
PORT=3001 npm run dev
```
