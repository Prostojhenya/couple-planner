# 🔄 Руководство по миграции: От "Пары" к "Группе"

## Что изменилось?

### Концепция
- **Было**: Планер для двоих (пары)
- **Стало**: Групповой планер (до 5 человек в Free, до 15 в Premium, до 50 в Team)

### Основные изменения

1. **Иконки кластера** 👥
   - Новый компонент `GroupClusterIcon`
   - Показывает количество участников
   - Разные цвета для разных тарифов:
     - Free: серый
     - Premium: фиолетовый ✨
     - Team: золотой 🚀
     - Lifetime: радужный ⭐

2. **База данных**
   - Добавлено поле `maxMembers` (по умолчанию 5)
   - Добавлено поле `subscription` (free/premium/team/lifetime)
   - Добавлено поле `name` для названия группы

3. **Терминология**
   - "Пара" → "Группа"
   - "Партнёр" → "Участник"
   - "Оба" → "Все"
   - "Создать пару" → "Создать группу"

4. **Лимиты**
   - Free: до 5 участников
   - Premium: до 15 участников
   - Team: до 50 участников

## Новые компоненты

### GroupClusterIcon

```tsx
import GroupClusterIcon from '@/components/GroupClusterIcon';

<GroupClusterIcon 
  memberCount={3} 
  maxMembers={5}
  subscription="free"
  size="md"
  showCount={true}
/>
```

**Props:**
- `memberCount` - количество участников
- `maxMembers` - максимум участников
- `subscription` - тариф (free/premium/team/lifetime)
- `size` - размер (sm/md/lg)
- `showCount` - показывать ли счётчик

## Обратная совместимость

Все существующие данные сохранены:
- Существующие "пары" автоматически стали "группами"
- `maxMembers` установлен в 5 для всех существующих записей
- `subscription` установлен в 'free' для всех существующих записей
