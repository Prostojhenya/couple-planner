# Установка приложения на мобильное устройство

## Что изменилось:

✅ Добавлен полноэкранный режим (PWA)
✅ Убраны панели браузера на мобильных
✅ Поддержка безопасных зон (iPhone notch)
✅ Приложение работает как нативное

## Как установить на iPhone/iPad:

1. Откройте приложение в Safari
2. Нажмите кнопку "Поделиться" (квадрат со стрелкой вверх)
3. Прокрутите вниз и выберите "На экран «Домой»"
4. Нажмите "Добавить"
5. Готово! Теперь приложение открывается в полноэкранном режиме

## Как установить на Android:

1. Откройте приложение в Chrome
2. Нажмите меню (три точки)
3. Выберите "Добавить на главный экран" или "Установить приложение"
4. Нажмите "Установить"
5. Готово! Приложение работает как нативное

## Преимущества:

- 📱 Полноэкранный режим без панелей браузера
- 🚀 Быстрый запуск с главного экрана
- 💾 Работает офлайн (после первого запуска)
- 🎨 Собственная иконка на главном экране
- ⚡ Ощущается как нативное приложение

## Технические детали:

- `display: standalone` - полноэкранный режим
- `viewport-fit: cover` - использование всего экрана
- `safe-area-inset-*` - поддержка вырезов iPhone
- `apple-mobile-web-app-capable` - режим веб-приложения
- `theme-color` - цвет строки состояния
