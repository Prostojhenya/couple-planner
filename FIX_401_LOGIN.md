# 🔐 Исправление ошибки 401 при входе

## Проблема
`POST /api/auth/login` возвращает 401 (Unauthorized) с сообщением "Неверный email или пароль"

## Причина
Пользователь не существует в production базе данных.

## ✅ Решение (выберите один вариант)

### Вариант 1: Регистрация через UI (Рекомендуется)

1. Откройте: https://couple-planner-ten.vercel.app/auth/register
2. Заполните форму:
   - Email: ваш email
   - Пароль: минимум 8 символов
   - Имя: ваше имя (опционально)
3. Нажмите "Зарегистрироваться"
4. Вы автоматически войдёте в систему
5. Теперь можно использовать эти данные для входа

### Вариант 2: Создание пользователя через скрипт

Если нужно создать пользователя программно:

```bash
# 1. Получите DATABASE_URL из Vercel Dashboard
# Settings → Environment Variables → DATABASE_URL

# 2. Создайте пользователя с дефолтными данными
DATABASE_URL="your_production_url" node create-production-user.js

# Или с кастомными данными:
DATABASE_URL="your_production_url" USER_EMAIL="myemail@example.com" USER_PASSWORD="mypassword123" USER_NAME="My Name" node create-production-user.js
```

Скрипт выведет:
```
✅ Пользователь успешно создан!

📋 Данные для входа:
   📧 Email: test@example.com
   🔑 Пароль: password123
   👤 Имя: Test User
   🆔 ID: clxxx...
```

### Вариант 3: Проверка существующих пользователей

Если не уверены, есть ли пользователи в базе:

```bash
# Откройте Prisma Studio
DATABASE_URL="your_production_url" npx prisma studio

# Перейдите в таблицу User
# Если пользователей нет - используйте Вариант 1 или 2
```

## 🔍 Проверка

После создания пользователя:

1. Откройте: https://couple-planner-ten.vercel.app/auth/login
2. Введите email и пароль
3. Должны успешно войти
4. Перейдите в `/onboarding` для создания группы

## 📝 Примечания

- Пароль должен быть минимум 8 символов
- Email должен быть уникальным
- После входа нужно создать группу через onboarding
- Без группы API `/tasks` и `/events` будут возвращать 400

## 🚀 Следующие шаги

После успешного входа:

1. ✅ Войти в систему
2. ✅ Пройти onboarding
3. ✅ Создать группу/пространство
4. ✅ Начать использовать приложение

## ⚠️ Важно

Если ошибка 401 остаётся после создания пользователя:

1. Проверьте, что используете правильный email
2. Проверьте, что пароль совпадает (минимум 8 символов)
3. Проверьте логи Vercel: `vercel logs`
4. Убедитесь, что миграции применены: см. `VERCEL_FIX_GUIDE.md`
