# Исправление ошибки комментариев

## Проблема
Ошибка 500 при попытке создать комментарий:
```
POST /api/comments 500 (Internal Server Error)
```

## Причина
Таблица `comments` не существует в production БД (Supabase).
Миграция не применилась автоматически.

## Решение

### Вариант 1: Через Supabase SQL Editor (РЕКОМЕНДУЕТСЯ)

1. Открой [Supabase Dashboard](https://supabase.com/dashboard)
2. Выбери свой проект
3. Перейди в **SQL Editor** (слева в меню)
4. Создай новый запрос
5. Скопируй содержимое файла `APPLY_COMMENTS_MIGRATION.sql`
6. Вставь в редактор
7. Нажми **Run** (или F5)
8. Должно появиться: "Comments table created successfully!"

### Вариант 2: Через Prisma (если есть доступ к БД локально)

```bash
# В терминале
npx prisma migrate deploy
```

### Вариант 3: Через Vercel CLI

```bash
# Установи Vercel CLI если нет
npm i -g vercel

# Логин
vercel login

# Перейди в проект
cd G:\Users\prost\Desktop\планер

# Запусти миграцию
vercel env pull .env.production
npx prisma migrate deploy --schema=./prisma/schema.prisma
```

## Проверка

После применения миграции:

1. Обнови страницу приложения (F5)
2. Открой любую задачу
3. Прокрути вниз до "💬 Комментарии"
4. Попробуй написать комментарий
5. Нажми "Отправить"

Если всё работает - увидишь свой комментарий!

## Альтернатива: Временно отключить комментарии

Если не хочешь возиться с миграцией сейчас, можно временно скрыть комментарии:

1. Открой `src/app/dashboard/page.tsx`
2. Найди `<CommentSection` (2 места - в Task и Event модалках)
3. Закомментируй эти блоки:
```tsx
{/* Временно отключено
<CommentSection
  entityType="task"
  entityId={selectedTask.id}
  currentUserId={user?.id}
/>
*/}
```
