# 📱 Инструкция: Push-уведомления на iPhone

## ✅ Что уже готово:

- ✅ VAPID ключи настроены
- ✅ Dev-сервер запущен
- ✅ Service Worker готов
- ✅ Тестовый скрипт создан
- ✅ ngrok установлен

## 🎯 Что нужно сделать:

### 1️⃣ Настроить ngrok (5 минут)

**А. Регистрация:**
1. Откройте https://ngrok.com/
2. Нажмите "Sign up" (бесплатно)
3. Зарегистрируйтесь через email или GitHub

**Б. Получите токен:**
1. После входа откройте: https://dashboard.ngrok.com/get-started/your-authtoken
2. Скопируйте authtoken (выглядит как: `2abc123def456ghi789jkl`)

**В. Настройте ngrok:**

Выполните в терминале (замените YOUR_TOKEN):
```bash
ngrok config add-authtoken YOUR_TOKEN
```

Пример:
```bash
ngrok config add-authtoken 2abc123def456ghi789jkl
```

### 2️⃣ Запустить туннель

**Вариант А: Автоматический (проще)**

```bash
node start-ngrok.js
```

Скрипт автоматически:
- Запустит ngrok туннель
- Получит HTTPS URL
- Обновит .env файл
- Покажет следующие шаги

**Вариант Б: Вручную**

```bash
# В новом терминале:
ngrok http 3000
```

Вы увидите:
```
Forwarding    https://abc123.ngrok.io -> http://localhost:3000
```

Скопируйте HTTPS URL и обновите `.env`:
```env
NEXTAUTH_URL="https://abc123.ngrok.io"
```

### 3️⃣ Перезапустить dev-сервер

```bash
# Остановите текущий (Ctrl+C)
npm run dev
```

### 4️⃣ Настроить iPhone

**На iPhone:**

1. **Откройте Safari**
   - Не Chrome! Только Safari поддерживает PWA на iOS

2. **Перейдите на ngrok URL**
   - Например: `https://abc123.ngrok.io`
   - URL показан в консоли после запуска ngrok

3. **Войдите в систему:**
   - Email: `test@test.com`
   - Пароль: `test1234`

4. **Установите как PWA:**
   - Нажмите кнопку "Поделиться" (квадрат со стрелкой вверх внизу экрана)
   - Прокрутите вниз
   - Выберите "На экран «Домой»"
   - Нажмите "Добавить"

5. **Запустите приложение:**
   - Найдите иконку на домашнем экране
   - Нажмите на неё
   - Приложение откроется в полноэкранном режиме

6. **Разрешите уведомления:**
   - Появится запрос на разрешение
   - Нажмите "Разрешить"

### 5️⃣ Проверить работу

**На компьютере:**

```bash
node test-push-notification.js
```

**На iPhone должно прийти уведомление!** 🎉

## 🔍 Проверка настроек iOS

Если уведомления не приходят:

1. **Настройки → Уведомления → [Ваше приложение]**
2. Убедитесь, что включено:
   - ✅ Разрешить уведомления
   - ✅ Звуки
   - ✅ Баннеры
   - ✅ На экране блокировки

3. **Проверьте версию iOS:**
   - Настройки → Основные → Об этом устройстве
   - Должна быть **iOS 16.4 или выше**

## 🐛 Решение проблем

### "ERR_NGROK_108" или туннель не запускается:
```bash
# Проверьте конфигурацию:
ngrok config check

# Если токен не настроен:
ngrok config add-authtoken YOUR_TOKEN
```

### Приложение не открывается на iPhone:
- ✅ Используете HTTPS URL? (не HTTP)
- ✅ ngrok туннель запущен?
- ✅ Dev-сервер запущен?
- ✅ Открываете в Safari? (не Chrome)

### Уведомления не приходят:
1. ✅ iOS 16.4 или выше?
2. ✅ Приложение установлено как PWA?
3. ✅ Запускаете через иконку на домашнем экране?
4. ✅ Разрешения даны в настройках iOS?
5. ✅ Подписка сохранена? (проверьте: `node test-push-notification.js`)

### Подписка не сохраняется:
- Проверьте консоль браузера (Safari → Разработка → iPhone → Консоль)
- Проверьте, что VAPID ключи в .env
- Перезапустите dev-сервер после изменения .env
