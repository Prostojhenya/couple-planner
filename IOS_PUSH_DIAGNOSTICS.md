## ⚠️ Критические ограничения iOS:

### 1. Минимальная версия iOS
- **Требуется iOS 16.4+** (март 2023)
- Проверьте: Настройки → Основные → Об этом устройстве → Версия ПО

### 2. Только для установленных PWA
- ❌ **НЕ работает в Safari браузере**
- ✅ **Работает только в PWA**, установленном через "Add to Home Screen"

### 3. Требуется HTTPS
- ❌ `http://localhost:3000` НЕ работает на iOS
- ✅ Нужен HTTPS или публичный домен

### 4. Ограниченная функциональность
- Меньше возможностей, чем на Android/Desktop
- Могут быть задержки в доставке

## 🚀 Как протестировать на iOS:

### Вариант 1: Локальное тестирование (требует дополнительной настройки)

1. **Установите ngrok для HTTPS туннеля:**
   ```bash
   npm install -g ngrok
   ngrok http 3000
   ```

2. **Получите HTTPS URL** (например: `https://abc123.ngrok.io`)

3. **Обновите .env:**
   ```env
   NEXTAUTH_URL="https://abc123.ngrok.io"
   ```

4. **Перезапустите сервер:**
   ```bash
   npm run dev
   ```

5. **На iPhone:**
   - Откройте Safari
   - Перейдите на `https://abc123.ngrok.io`
   - Войдите в систему
   - Нажмите "Поделиться" → "На экран «Домой»"
   - Запустите приложение через иконку
   - Разрешите уведомления

### Вариант 2: Deploy на Vercel/Netlify (рекомендуется)

1. **Deploy приложение:**
   ```bash
   vercel deploy
   # или
   netlify deploy
   ```

2. **Получите HTTPS URL** (например: `https://your-app.vercel.app`)

3. **На iPhone:**
   - Откройте Safari
   - Перейдите на ваш HTTPS URL
   - Войдите в систему
   - Установите как PWA
   - Разрешите уведомления

## 🧪 Тестирование уведомлений:

### После установки PWA и разрешения уведомлений:

1. **Проверьте подписку:**
   ```bash
   node test-push-notification.js
   ```

2. **Создайте задачу для партнёра** с другого устройства

3. **Проверьте настройки iOS:**
   - Настройки → Уведомления → [Ваше приложение]
   - Убедитесь, что уведомления включены

## 🔧 Альтернативные решения:

Если iOS push-уведомления критичны, но не работают:

### 1. Сторонние сервисы (работают лучше на iOS):
- **OneSignal** - бесплатный план, хорошая поддержка iOS
- **Firebase Cloud Messaging** - от Google
- **Pusher Beams** - простая интеграция

### 2. Email уведомления как fallback:
- Отправка email при создании задачи
- Работает на всех устройствах

### 3. In-app уведомления:
- Показ уведомлений внутри приложения
- Polling или WebSocket для real-time обновлений

## 🐛 Troubleshooting:

### Уведомления не приходят на Desktop:
- Проверьте консоль браузера (F12)
- Проверьте DevTools → Application → Service Workers
- Проверьте DevTools → Application → Notifications

### Уведомления не приходят на iOS:
1. Версия iOS 16.4+?
2. Приложение установлено как PWA?
3. Используется HTTPS?
4. Разрешения даны в настройках iOS?
5. Приложение не в фоновом режиме слишком долго?

### Service Worker не регистрируется:
- Очистите кэш браузера
- Проверьте, что файл `public/sw.js` существует
- Убедитесь, что используется HTTPS (или localhost)
