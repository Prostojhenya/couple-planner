# Комментарии к задачам и событиям

## ✅ Реализовано

### Backend (API)
1. **POST /api/comments** - Создание комментария
   - Валидация данных (zod)
   - Проверка существования задачи/события
   - Автоматическое добавление автора

2. **GET /api/comments?entityType=task&entityId=xxx** - Получение комментариев
   - Фильтрация по типу и ID сущности
   - Сортировка по дате создания (старые → новые)
   - Включение информации об авторе

3. **DELETE /api/comments/[id]** - Удаление комментария
   - Проверка прав (только автор может удалить)
   - Каскадное удаление при удалении задачи/события

### Frontend (UI)
1. **CommentSection компонент** (`src/components/CommentSection.tsx`)
   - Отображение списка комментариев
   - Форма добавления нового комментария
   - Удаление своих комментариев
   - Loading states
   - Счетчик символов (макс 1000)
   - Автоматическая прокрутка

2. **Интеграция в модальные окна**
   - Task Detail Modal - комментарии к задачам
   - Event Detail Modal - комментарии к событиям

### База данных
1. **Миграция** `20260128120000_add_comments_support`
   - Таблица comments
   - Foreign keys к tasks и events
   - Каскадное удаление

## 🎨 UI/UX особенности

### Дизайн комментариев
- Аватарки с инициалами (градиент blue→purple)
- Имя автора и дата
- Кнопка удаления (только для своих)
- Серый фон для визуального разделения

### Форма добавления
- Textarea с автоматическим ресайзом
- Счетчик символов 0/1000
- Кнопка "Отправить" (disabled если пусто)
- Loading state при отправке

### Empty state
- "Пока нет комментариев" когда список пуст
- Приглашение добавить первый комментарий

## 🚀 Как использовать

### В коде
```tsx
<CommentSection
  entityType="task" // или "event"
  entityId={task.id}
  currentUserId={user?.id}
  onCommentAdded={() => console.log('Комментарий добавлен')}
/>
```

### Для пользователя
1. Открыть задачу или событие
2. Прокрутить вниз до секции "💬 Комментарии"
3. Написать комментарий в поле
4. Нажать "Отправить"
5. Удалить свой комментарий кнопкой 🗑️

## ✨ Особенности реализации

### Безопасность
- Проверка авторизации на всех эндпоинтах
- Проверка прав на удаление (только автор)
- Валидация длины текста (1-1000 символов)

### Производительность
- Загрузка комментариев только при открытии модалки
- Оптимистичные обновления UI
- Минимальные запросы к БД

### Масштабируемость
- Универсальный entityType (можно добавить notes, shopping и т.д.)
- Отдельная таблица comments
- Каскадное удаление
